# Periodic Table Explorer

A no-login, responsive periodic-table learning website designed for deployment on Railway.

## Run locally
1. Install Node.js 18+.
2. In this folder run:
   `npm start`
3. Open http://localhost:3000

## Railway
Create a new Railway service from this project/repository. Railway will use the `start` script in package.json:
`node server.js`

No database, authentication, environment variables, or external API are required.

## Included
- All 118 elements
- Correct 18-column periodic-table layout
- Separate lanthanide and actinide rows
- Search by name, symbol or atomic number
- s/p/d/f block filters
- Metal / metalloid / non-metal / noble-gas filters
- p-block colour coding by Groups 13–18
- Element detail cards
- Electronic configurations
- Physical state, density, melting/boiling point fields
- Oxidation states and flame colours where relevant
- Oxide/hydroxide nature
- Crystal/unit-cell section
- Occurrence, applications and interesting facts
- Periodic-trend section
- Mobile responsive interface
