How to use

Use the search box to find an element by name, symbol or atomic number. Filters can isolate s, p, d or f blocks and broad element types.

The p-block is colour-coded by Groups 13–18 so that carbon group, nitrogen group, oxygen group, halogens and noble gases are visually separated.

Click an element to open its study card. The card includes chemistry, structure, occurrence, applications and an interesting fact.
